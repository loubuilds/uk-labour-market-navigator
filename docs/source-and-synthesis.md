# Source and synthesis boundary

The workforce evidence uses the qualified ONS occupation workbook released 31 May
2023, Census Day 21 March 2021, with SOC2020 unit groups. It does not claim a live
source refresh or the newest observations. Reference metadata and snapshot bytes
are independently pinned in installed code. The source workbook and SOC archive
are included so extraction and classifications can be reproduced offline.

Counts are publisher estimates rounded to five; shares are published to one
decimal. Local and England/Wales shares define concentration. Its rounding range
is not a confidence interval. Use the published population, whole occupation,
source boundary and disclosure caveats. Missing or suppressed values remain gaps.
A missing selected comparison row withholds the comparison instead of dropping it.

Source readers and software are by Louise Mead. Official public data retains its original attribution and source-specific hashes. The current software licence does not retrospectively revoke earlier grants.

## What verification establishes

- The accepted scope matches the installed source registry.
- Saved factual evidence reproduces from the fixed qualified source snapshot.
- Narrative references point to real facts; numerical tokens in free prose fail.
- Readable report, chart, table and ledger reproduce from the checked evidence
  and recorded synthesis. Edited or missing report files withhold reuse of both readable
  surfaces; verification leaves their files intact. Changing a manifest alone cannot approve fabricated numbers.

## What it does not establish

- That arbitrary prose was interpreted correctly or the person actually consented.
- That the host's interpretation is true, helpful, complete or free of causal
  overreach. It is visibly attributed as agent interpretation, never source fact.
- That digit-free prose cannot contain an invented qualitative or spelled-out
  numerical claim. The host must review its narrative; keyword filtering would
  not solve this semantic problem.
- Cryptographic authorship. These hashes are not signatures. A person changing
  the trusted installation or rewriting prose and its seals can defeat that
  boundary. Qualified numeric replay still checks against installed source bytes.
- That a static HTML file reverifies itself, or an old snapshot is current.

The separate narrative
stage is intentional: useful synthesis belongs inside the report, with a visible
distinction between checked evidence and judgement.
